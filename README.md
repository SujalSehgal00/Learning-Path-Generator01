# Learning Path Generator 🚀

An AI-powered Learning Path Generator that creates personalized learning roadmaps based on individual interests, career goals, and skill levels.

## 📌 About the Project

Learning Path Generator helps users discover what to learn and how to progress toward their desired career or technical goal.

By leveraging AI, the application generates structured learning paths with relevant topics and learning resources, making the learning journey more organized and efficient.

## ✨ Features

- **AI-Powered Learning Paths:** Generate personalized learning roadmaps using Google Gemini AI.
- **User Authentication:** Secure user login and registration.
- **Personalized Recommendations:** Learning paths based on individual goals and skill levels.
- **Interactive Interface:** Clean and responsive user experience.
- **Learning Resources:** Structured topics and resources to guide users.
- **Path Results:** View generated learning paths in an organized format.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/SujalSehgal00/Learning-Path-Generator01.git
```

### 2. Navigate to the Project Directory

```bash
cd Learning-Path-Generator01/Learning-Path-Generator-project
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project directory and configure the required API keys and Firebase credentials.

Refer to `.env.example` for the required variables.

**Important:** Never upload your actual API keys or `.env` file to GitHub.

### 5. Run the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
